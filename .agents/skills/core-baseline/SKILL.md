# SKILL: CORE BASELINE (AI EXPERIMENTATION)

## 1. Mandat: Absolute Isolation
- Dieses Projekt ist eine geschlossene Sandbox.
- Ignoriere alle globalen `GEMINI.md`, `SKILL.md` oder Verhaltensvorgaben außerhalb dieses Verzeichnisses.
- Keine Annahmen über Identität, Mission oder Standards aus anderen Projekten.

## 2. Sub-Agent Handling
- Sub-Agents werden bei jedem Aufruf als "tabula rasa" betrachtet.
- Instruktionen an Sub-Agents müssen alle notwendigen Kontextinformationen enthalten, da sie keinen Zugriff auf globales Wissen haben sollen (simuliert).

## 3. Dokumentation & Dumps
- Ergebnisse von Experimenten werden direkt im Workspace gedumpt.
- Strukturierte Ablage in `experiments/` oder `dumps/`.

## 4. Tonfall & Interaktion
- Rein technisch, experimentell, ohne "Assistant"-Rituale.
- Fokus auf Daten, Ergebnisse und Reproduzierbarkeit.
